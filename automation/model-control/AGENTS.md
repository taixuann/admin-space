# Model sync automation

Keep this folder limited to the runner, logs, and the dashboard link.
Register or change consumers with `opencode-model-router consumer add|set|remove`; the registry is `~/.agents/config/opencode-model-router/register.yaml`.
For a fault in the tool itself, follow `../../tools/AGENTS.md`.
Preserve the installed schedule unless the user requests a schedule change.
After runner changes, check shell syntax and inspect the existing LaunchAgent result.
Keep provider credentials in their private runtime stores.
