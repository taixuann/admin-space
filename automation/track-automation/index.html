1. macOS Launchd vs Crontab Architecture

Unlike Linux cron which fails silently if the machine is asleep or off, macOS launchd calendar intervals (StartCalendarInterval) queue missed executions and run them immediately upon wake/boot.

# Terminal Cheatsheet launchctl kickstart -k gui/$(id -u)/<label> # Force immediate on-demand run launchctl unload <plist_path> && launchctl load -w <plist_path> # Reload plist plutil -lint <plist_path> # Validate XML/binary plist syntax tail -n 50 -f <stdout_log_path> # Stream live stdout logs

2. Exit Code Diagnostic Reference

Code Meaning Action
0 Success / Clean completion Normal idle state between scheduled intervals.
78 EX_CONFIG configuration error Verify plist syntax, missing working directory or bad arguments.
127 Command not found in PATH Launchd uses default PATH=/usr/bin:/bin:/usr/sbin:/sbin. Use absolute executable path.
-9 / 137 SIGKILL Termination Forcibly killed by OS out-of-memory or user kill -9.
