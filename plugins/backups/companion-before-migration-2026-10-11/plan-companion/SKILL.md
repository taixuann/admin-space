# Plan Companion

Read [shared definitions](../companion/README.md) and the relevant references.
Use the settled discussion as the starting point. Inspect the actual target, schema and source context before drafting changes.
Use [Coverage and effects](../companion/references/working-context.md#coverage-and-effects) for any Project, Milestone, Task, Resource, Reference or note proposal. Carry the coverage receipt from the owning discussion and fill material gaps. Planning can support any of these object types without a weekly review.
Use [Working context](../companion/references/working-context.md) to reuse settled inputs and resolve required fields, identities and relation destinations.
If scope or content remains unresolved, return to [ask-companion](../ask-companion/SKILL.md) for that decision.

Present a short proposal in chat. Name the target records, exact edits or draft text, related effects, and remaining decisions. Distinguish recommended related changes from included changes.
For Overview layout changes, show one representative Milestone in the proposed format. State how the format applies to the other sections so the user can review it before writing.
For Evidence map changes, show the proposed groups, source links, reading purposes and material boundaries. Identify existing links or discrepancy notes to preserve or remove.
For Resource or log creation, include the existing template, actual Project relation, Scope, Status and any required schema change under [Resources](../companion/references/resources.md). For weekly review proposals, use [Weekly focus](../companion/references/weekly-focus.md) to show the bounded commitment and exact log and tab changes.
For a simple edit, one sentence can contain the complete proposal. Keep the proposal in chat by default. If a durable handoff is useful, propose a destination and save it only on request.

Keep planning read-only. Approval of the idea does not authorize edits that were not presented. When the user explicitly requests applying the concrete proposal, use [apply-companion](../apply-companion/SKILL.md).
An earlier explicit write request remains valid for its specified scope. Do not ask for the same authorization again unless a material decision remains unresolved.
Follow the next-step offers in [Working context](../companion/references/working-context.md#offer-the-next-step) after presenting the proposal.
