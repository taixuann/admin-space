# Weekly Review Companion

Read [shared definitions](../companion/README.md), [Working context](../companion/references/working-context.md) and [Weekly focus](../companion/references/weekly-focus.md).

Resolve the Project and review period from the conversation. Follow [Inventory and identify the week](../companion/references/weekly-focus.md#inventory-and-identify-the-week) to inventory the whole selected Project, recover the week's Task set and report coverage. Read the prior commitment and relevant log, note and Resource evidence even for work the user did not mention. If there was no previous commitment, say so and establish the first baseline with the user.

Compare intended work with reported and verified outcomes. Follow [Owner progress and recorded state](../companion/references/working-context.md#owner-progress-and-recorded-state): accept clear owner-confirmed completion over stale Status, then propose exact closure or reconciliation actions. Discuss remaining work, blockers and changed direction. Keep examples separate from actual progress. A completed Task does not establish a completed Milestone. Present proposed property changes separately from observations.

Help the user select next week's Milestones and a finite set of Tasks under [Priority eligibility](../companion/references/weekly-focus.md#priority-eligibility). Use [Consultation](../companion/references/consultation.md) within this review when candidates need purpose, placement, granularity or capacity discussion; retain the weekly inventory and carry settled inputs forward. Let the user author new Tasks unless creation is requested. Help resolve missing ownership, deadlines, priorities and completion criteria. Keep unresolved values visible.

Return a concrete proposal in chat through [plan-companion](../plan-companion/SKILL.md). Include the review, bounded commitment, deferred work, open decisions and the exact canonical-record, log and tab edits. Continue discussion if decisions remain open.

When the user explicitly requests saving, follow [apply-companion](../apply-companion/SKILL.md). Reuse the Project's canonical Resource log and date toggle under [Capture and evidence](../companion/references/capture.md). Save the agreed review before updating its tab summary. Report the actual writes and unresolved parts. Invocation alone does not authorize edits.
