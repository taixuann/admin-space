# Review Companion

Read [source ownership](../../shared/references.md#source-ownership-and-reads), [authorization](../../shared/references.md#authorization-and-verification), [Notion review guidance](../../shared/references.md#notion-research-projects), and [domain guidance](../../shared/references.md#domain-guidance).

Resolve the project, topic or period. For weekly review, recover the explicit week, prior commitment and selected scope. Inventory selected work in its owning sources, follow pagination, read relevant records and logs, and report coverage. Include due, scheduled, reported, completed, carried-over, overdue or blocked work by canonical identity. If history or content is inaccessible, label the review partial; do not infer missing state.

Compare commitments with current records, dated evidence and the owner's latest clear report. Attribute each finding as scheduled, owner-reported, recorded or independently inspected. A Calendar event ending, due date, page edit date or commit count does not prove execution or completion. Accept clear owner confirmation for management progress without demanding repeated proof; distinguish it from scientific acceptance. A completed Task does not complete its Milestone automatically.

Report outcomes, deviations, blockers, source disagreements, useful evidence and unresolved work. Propose exact reconciliation when useful, but make no persistent change. Keep historical facts distinct from current properties and do not rewrite prior commitments.

Next week's focus belongs to Plan. Hand off to Plan only when the user asks to choose or settle next-period work, carrying the reviewed week, prior commitment, coverage, outcomes, eligible candidates and constraints. Specialized note organization, document maintenance, catalogue restructuring and merge planning belong only in Personal Hub, not global Review.
