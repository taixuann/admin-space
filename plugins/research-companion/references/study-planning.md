# Study planning coverage

Use this reference to review a Study plan. The current
the selected research-projects checkout’s `active-projects/.agents/skills/study/references/init.md` procedure remains the authority for
scientific admission and writes. This table maps it to the common template;
it does not replace that procedure.

| INIT aspect | Plan section and review question |
| --- | --- |
| FRAME | Purpose and scope: question, motivation, boundaries, owning Project and target identity |
| HYPOTHESIZE | Inputs and method: applicable alternatives, predictions and discriminators; descriptive limits when no hypothesis test is requested |
| Design support | Inputs and method: unresolved design/power needs and their assumptions; guidance only, no calculations |
| EVIDENCE | Context and evidence: existing knowledge, linked Story methods, then bounded external gaps; sources actually read and retrieval limits |
| Exact input selection | Inputs and method: IDs, paths, roles, display names, grouping units, exclusions and verification state |
| Material-decision gate | Requirements and decisions: scientist-supplied, verified metadata, ordinary elaboration, proposed material choice or essential unresolved choice |
| Evidence/output agreement | Requirements and decisions: each requested output answers a stated question within its interpretation limits |
| MATERIALIZE | Action steps: the exact three spec files and input.yaml, their content mapping and verification |
| Preservation and readiness | Review: empty new target, protected old work, raw integrity, no analysis before RUN and no implied next action |

Use only the aspects relevant to the question and owning action.
Keep the full table as a review aid, not a mandatory section in every plan.
For relevant aspects, state what is covered and what remains open.
Coverage means the plan explicitly addresses the aspect; it does not prove
scientific validity. Essential open decisions keep the plan DRAFT.

FRAME, HYPOTHESIZE and EVIDENCE can revise each other. Reopen only the part that
new evidence changes. Use the existing scientific skills on demand. For fixed
descriptive questions, keep the scope fixed and avoid manufactured mechanisms.

For input planning, distinguish stored metadata from live verified raw identity.
Before INIT, settle the exact input list and verify paths and hashes through the
owning workflow. A count in an old manifest cannot establish independent sample
size, equal protocols, device independence or fabrication equivalence.

For PREPARE, plan method-to-code translation and structural checks. For RUN,
plan preparation checks and the one execution scope. For RESULT, plan selected
locks and evidence dispositions. Planning never computes observations to settle
a scientific choice, and an approved plan never clears the owner's gates.
